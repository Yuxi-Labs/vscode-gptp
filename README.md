This extension adds support for developing GPTPs in VS Code.

## Features

- Syntax highlighting
- GPTP schema validation
- Auto-completion for roles (`system`, `user`, `assistant`)
- Hover tooltips
- Snippets

## File Support

Activated on files ending in `.gptp`.
