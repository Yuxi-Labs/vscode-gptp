# Commands

- GPTP: Insert Prompt Scaffold — Inserts a v1.2.0 scaffold into the active editor.
- GPTP: Insert Message Block — Adds a user/assistant/system message template.
- New GPT Prompt File — Opens a new v1.2.0 scaffold.
- GPTP: Validate Current Prompt — Runs schema and semantic checks; results in Problems.
- GPTP: Execute Preview (Resolved Messages) — Resolves variables and shows messages; no provider call.
- GPTP: Run with Model — Prompts for required vars, executes, and shows results in a Markdown tab.
- GPTP: Migrate Prompt to v1.2.0 — Upgrades older documents.
- GPTP: Diff Prompt Keys (2 open docs) — Compares top‑level keys from two open GPTP files.
